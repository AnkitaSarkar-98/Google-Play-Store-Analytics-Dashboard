# Google Play Store Market Analytics Dashboard

## Overview
This repository contains an interactive analytics dashboard designed to analyze the Google Play Store mobile app ecosystem. The dashboard provides critical market insights into app distributions across categories, total installs, review trends, pricing models (Free vs. Paid), and Android OS version compatibility.

### Key Metrics & Highlights
* **Average Rating:** 4.0
* **Total Applications Analyzed:** 9,638 apps
* **Total Install Volume:** 146.63 Billion+ installs
* **Total User Reviews:** 4.20 Billion+ reviews
* **Monetization Breakdown:** 92.19% Free Apps vs. 7.81% Paid Apps

### Core Insights
* **Top Categories by Volume:** The **Family** category leads with 7,200 apps, followed by **Game** (4,598 apps) and **Tools** (2,971 apps).
* **Install Heavyweights:** **Communication**, **Game**, **Tools**, and **Productivity** represent the largest proportion of market install volumes.
* **OS Distribution:** Most applications target **Android 4.0.3 and up** (5,075 apps), **Android 4.0 and up** (4,559 apps), or vary dynamically by device (5,031 apps).

## Conclusion
The dashboard demonstrates that while categories like Family and Game dominate overall app volume, high-utility categories like Communication, Productivity, and Tools drive the bulk of total market installations. Furthermore, keeping app dependencies compatible with Android 4.0+ or device-adaptive builds maximizes target reach across the ecosystem.
